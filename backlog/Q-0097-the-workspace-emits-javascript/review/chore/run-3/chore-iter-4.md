major: packages/cli/src/build.test.ts:286 `isTurboMetadata` exempts every path containing a `.turbo` segment, not only Turbo’s own cache metadata and logs. A build script can write an undeclared artifact such as `.turbo/stray.js`, and the exact-output audit will discard it despite AC-8 granting only an exemption for Turbo-generated metadata. This also contradicts the adjacent claim that an artifact hidden beside a log remains reportable. Restrict the exemption to paths positively identified as Turbo-generated metadata/logs, and add a mutation proving an arbitrary build-created file under `.turbo` fails the audit.

major: packages/cli/src/build.test.ts:359 The isolated audit represents installed dependencies with symlinks and treats each symlink as an unaudited leaf. A changed build script can write through one of these links—for example into `node_modules/typescript/...`—modifying the real installation outside the isolated root while both the symlink fingerprint and isolated inventory remain unchanged. This violates AC-8’s exact write-set requirement and E-2’s assertion that the isolated audit descends into `node_modules` without a blind spot. Use an actually isolated dependency tree or snapshot and compare the symlink targets as part of the audit, and add a mutation demonstrating that a write through a dependency path is reported.
