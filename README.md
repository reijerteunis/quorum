# Quorum

Open-source, local-first mission control for agentic software engineering. Define your
development flow once as versioned files, run it with coding agents from multiple vendors —
competing coders, cross-vendor review panels, judges — on the subscriptions you already pay
for, with a human gate between every step. Nothing advances without a quorum.

Status: pre-alpha. The runnable piece is the spike in `spike/`; the product plan is in
`docs/06-development-plan.md`. Start with `docs/README.md`.

Launching via [heyruud.com](https://heyruud.com).
